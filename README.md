# PyWars

PyWars is where I practice Python for class and for [Codewars](https://www.codewars.com/) kata.

## How I use it

1. Pick a kata on Codewars.
2. Copy the kata's starter code into a new `.py` file here.
3. Work on it in VS Code or PyCharm, where I can run and debug the code.
4. When it works, copy my solution back into Codewars and submit it.

## Files

Each `.py` file is one class exercise or Codewars kata, for example:

- `hello.py`
- `about_me.py`
